# Shared public snapshot client

The desktop can optionally read the public field from one explicitly configured shared snapshot service. Set `INTOPONET_SHARED_PUBLIC_SNAPSHOT_URL` to an HTTPS origin such as `https://snapshots.example`. No endpoint is built in and no service is deployed by this client change. The configured value must be an origin only: credentials, paths, query strings, fragments, and non-HTTPS schemes are rejected.

When the setting is present, the desktop requests only `GET /latest` and the immutable `GET /snapshots/<snapshot-id>` named by that manifest. Requests send no browser profile, headline, location, or other personal data; credentials and referrers are omitted and redirects are rejected. Both responses have strict byte limits and a 10-second timeout. If the setting is absent, the existing local public-field refresh path remains in use. If it is present but invalid or unavailable, the desktop does not fall back to independently recomputed local public-field data.

The client validates the manifest schema and canonical path, HTTPS origin, snapshot ID, SHA-256 of the exact artifact bytes, field-snapshot v2 schema, `log1p-separated-v3` algorithm, public-only records and bands, attribution, canonical serialization, and equality between artifact ID/evaluation time and manifest values. Evaluation times more than five minutes ahead of the client clock are rejected. Parsing verifies the normalized derived bands using the artifact's own `createdAt`; the local clock is not passed into snapshot aggregation. A valid shared artifact and its coverage/attribution are cached separately from the independent local-source cache, scoped to the configured origin, and revalidated when read. The cache is atomically replaced and stored with user-data permissions; a failed write or rename removes its temporary file.

If refresh fails, a verified cache remains available with an explicit `cached`, `stale`, or `error` status and a safe message from `publicFieldStatus()`. The status ages to stale after two hours, matching the renderer's globe freshness threshold, even when no later refresh occurs. With no verified cache, the client returns no public snapshot. The renderer receives the mode, source label, configured origin, status, evaluation time, and message over a separate status event and displays them beside the coverage note; these details do not modify the canonical snapshot or its ID.

This contract covers the `FieldSnapshot` artifact only. RSS and news ingestion use a separate feed cache and are not included in this agreement. Matching public-field snapshot IDs does not mean clients have identical news feeds, browsing activity, or all other data, and the snapshot ID is a content identity rather than a publisher signature.

## Focused verification

`npm run test --workspace @intoponet/desktop -- src/main/shared-public-field.test.ts src/main/public-field.test.ts` checks same-artifact results across different client clocks, aging to stale after a successful fetch, future-time rejection, artifact tampering, size limits, failed atomic-write cleanup, offline verified-cache retention, unsafe endpoint URLs, fixed credential-free requests, and the configured-source no-fallback path.
